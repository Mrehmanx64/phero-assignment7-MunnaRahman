# বাজার দর (BazarDor)

বাজার দর (BazarDor) is a comprehensive web application designed to track and display daily market prices for essential commodities. It helps users make informed decisions by providing up-to-date information on price trends, enabling better budgeting and shopping.

## Technologies Used
- **Next.js**: Framework for building the UI and handling routing.
- **Tailwind CSS**: For styling and ensuring a responsive design.
- **HeroUI**: Component library for modern UI elements.
- **TypeScript**: For type safety.
- **BetterAuth**: For secure user authentication (Email/Password, Google, GitHub).
- **MongoDB**: Database for storing user data.

## Key Features
1. **Real-time Price Ticker**: An infinite scrolling marquee displaying current market price changes for essential items.
2. **Comprehensive Product Tracking**: Dedicated sections for top risers, top fallers, and all products, with responsive grid layouts.
3. **Advanced Product Details**: Protected route for logged-in users to view detailed market summaries and price trends for specific products.
4. **Category-based Browsing**: Filter and sort products by category with support for different sorting criteria (default, price low-to-high, price high-to-low).
5. **Secure Authentication & User Profile**: Support for email/password, Google, and GitHub login with profile management and information update capabilities.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) with your browser.
